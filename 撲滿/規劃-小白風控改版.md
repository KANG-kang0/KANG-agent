## 設計哲學（為什麼這樣改，不要偏離）

新手虧錢的原因排序：**行為（追高、凹單、重倉）> 部位（一單梭哈）> 選股（挑錯股）**。
但市面上所有工具都反過來只做選股。所以本產品的價值排序是：**防呆 > 算部位 > 給訊號**。

North star 一句話：「這個 app 不幫你賺快錢，它幫你活得夠久、學會不變韭菜。」

砍掉的東西（跟加法一樣重要，未來 session 不要提議加回來）：
- 策略只對使用者曝光 `bollinger_regime`（含稅回測唯一過門檻者，見判斷檔）；其他策略碼保留供研究，不進推播與 UI
- 不做：當沖、融資、選擇權、排行榜、任何比較別人績效的功能
- 低波動存股型股票（如 2412）不進波段清單：screen 加波動門檻（近 60 日年化波動 < 15% 排除）

## 產品四支柱

### 支柱一：三道防線（把 config 常數變成「看得見的保護」）
1. **每單防線**：股數由 `RISK_PER_TRADE`（每單最多賠總資金 1.5%）反推——進場訊息必須顯示「**這單最多賠 X 元**」，金額不是百分比，小白對金額才有感
2. **每週防線**：熔斷進度（本週已虧 X% / 上限 6%），視覺化成進度條
3. **行為防線**：連虧 3 單 → 冷靜一天（app 端拒絕新單並說明為什麼）

**可行性依據**：`config.py` 已有 RISK_PER_TRADE、MAX_DAILY_LOSS、MAX_WEEKLY_LOSS、MAX_CONCURRENT、COOLDOWN_AFTER_LOSSES 全套常數；Supabase `profiles` 表已有對應欄位（capital、max_daily_loss、max_weekly_loss、max_concurrent、cooldown_losses）；`positions.realized_ret` 已存在可算已實現損益。**全部是呈現與檢查邏輯，不需要新資料源。**

### 支柱二：開戶三問（onboarding）
新手不該看到 `DISASTER_STOP=0.15`。第一次使用問三題，之後全自動：
1. 「你拿多少錢來玩波段？」（強調：只能是虧光也不影響生活的錢）→ `capital`
2. 「一個月最多賠多少你睡得著？」→ 反推 max_weekly_loss 與 RISK_PER_TRADE
3. 「你的目標？」（a 學會操作 b 加菜金 c 認真滾雪球）→ 決定 top_n 與推播語氣

**可行性依據**：`profiles` 欄位齊全、`撲滿-web/app.js`（約 1000 行）已接 Supabase auth。純前端表單＋一次 upsert。

### 支柱三：一天三句話（推播全面改版，本改版的核心體驗）
每日收盤後推播固定三段，**沒訊號也要推**（訓練「不動也是操作」）：
```
🌤 大盤：綠燈（加權指數在年線上，可以正常operate）
📦 你的持倉：3044 續抱（還沒到 +10%，持有 12/30 天）——沒到出場條件就不動，這就是紀律
🌱 今天的機會：沒有。錢留著，機會天天有，本金只有一副。
```
有機會時第三段變成：
```
🌱 2454 聯發科 到了「多頭回檔的便宜區」（跌破布林下軌但仍在年線上）
   買 X 股（約 Y 元）｜最多賠 Z 元｜目標 +10%｜最久抱 30 天
   ⚠️ 供參考非投資建議；只用閒錢，分批進。
```
規則：機會**一天最多一檔**（top_n 對新手強制 =1）；每句話都要有「為什麼」；尾註照話術判斷檔。

**可行性依據**：`daily_job.py` 的 `run_cloud()` 已在做 per-user Telegram 推播（`notify.send_to`）、`_picks_section`/`_positions_section` 已有雛形——這是**重寫文案與精簡邏輯**，不是新功能。大盤紅燈綠燈＝「指數收盤 vs 200 日線」，與策略同源。
**待驗證點（實作 session 第一件事）**：FinMind 抓大盤指數用 dataset `TaiwanStockPrice`、data_id `TAIEX` 試一次；抓不到就改用 `0050` 當大盤 proxy（0050 一定抓得到，語意等價）。

### 支柱四：紙上駕訓班（paper mode）
新手前 5 單強制虛擬單：流程完全一樣（推播、進出提醒、損益結算），但不動真錢。
畢業條件**不是賺錢**，是「完整走完 5 次進出、沒有一次違規（凹單/超額）」。畢業推播給一張成績單。

**可行性依據**：`positions` 表加一個 `is_paper boolean default false` 欄位＋前端標示＋熔斷計算排除 paper 單。回測引擎已能算所有出場規則，paper 單只是「用真行情走假部位」。

## 給股票新手的建議（產品之外，寫給使用者本人）

1. **前三個月的目標是「活著＋守規則」，不是賺錢。** 用 paper mode 的心態看待真錢的前十單：學費預算先想好。
2. **本金分層**：緊急預備金（6 個月生活費）→ 存股/指數（大部位）→ 波段（本系統，只放虧光不心疼的錢）。本系統永遠只碰第三層。
3. **唯一該背的公式**：股數 =（總資金 × 1.5%）÷（進場價 × 15%）。它保證你連錯 10 次也只賠 15%，還活著。
4. 別人報明牌時，讓系統回答三個問題：在年線上嗎？在便宜區嗎？部位算出來多大？三關都過才考慮——**過濾器比明牌值錢**。
