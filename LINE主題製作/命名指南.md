# LINE 主題製作 — 使用說明

## 你只要做兩件事
1. 開一個工作資料夾，把要替換的照片丟進去，用**數字代號**命名
2. 跟 Claude 說「做 LINE 主題」或直接執行腳本

## 命名對照（副檔名 jpg / png / webp 都可以）

| 你命名 | 會變成 | 用途 |
|---|---|---|
| `i22.jpg` | i_22 | iOS 聊天室背景 |
| `a22.jpg` | a_22 | Android 聊天室背景 |
| `i27.png` | i_27 + i_27_g | iOS 分頁圖示（自動生灰階） |
| `i25`~`i38` | 對應 i_XX + _g | iOS 各分頁圖示 |
| `i12`~`i21` | 對應 i_XX | iOS 貼圖 |
| `a12`~`a22` | 對應 a_XX | Android 貼圖／背景 |
| `store.jpg` 或 `main.jpg` | 三種縮圖 | 商店/iOS/Android 縮圖 |

> 只放要換的即可，沒放的會自動用範本（template/）補齊，一定湊滿 61 檔。

### 已知分頁功能
- i_27 / i_28 = 錢包 OFF / ON
- i_29 / i_30 = 主頁 OFF / ON
- i_33 / i_34 = VOOM OFF / ON
- i_35 / i_36 = Shopping OFF / ON

## 執行
```bash
python3 build_theme.py <你的工作資料夾>
```
完成後會得到：
- `<工作資料夾>/_上傳版/`：61 個主題檔
- `<工作資料夾>_上傳版.zip`：直接上傳 LINE Creator

## 檔案結構
- `build_theme.py` — 處理引擎
- `theme_spec.json` — 尺寸規格（從 template 掃出，改版可重掃）
- `template/` — 現有合格主題（當範本＋補齊缺檔）
- `命名指南.md` — 本檔

## 三個已內建的重點（不用你操心）
1. 灰階版透明底正確（不會變黑塊）
2. 聊天背景自動壓到 <1MB（LINE 上限）
3. 打包只收合法檔，來源照片不會被誤包
